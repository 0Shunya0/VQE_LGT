# Bug 2: independent verification of the N=2,3,4 phase boundary

Generated by `check_boundary.py`. Ground-state energy E(K) and flavor-0
occupation <N_0> computed by direct exact diagonalization
(`schwinger_core.exact_ground_state_full`) on a fine grid K = linspace(0, 8,
161), x=16, convention "nu0only", independent of `boundary_K()`. Two
independent signatures were used: the largest discontinuity in dE/dK, and the
largest jump in <N_0> (first-order transitions here are level crossings
between different flavor-0-occupation sectors, so they must show up as a
near-integer jump in <N_0> at the same K as any genuine slope discontinuity).

## Summary table

| N | kb via dE/dK jump | kb via largest N0 jump | boundary_K() | Agree? |
|---|---|---|---|---|
| 2 | 3.950 | 3.950 | 3.950 | yes |
| 3 | 5.600 | 5.600 | 5.600 | yes |
| 4 | 2.500 | 6.400 | 2.500 | **no** |

N=2 and N=3 are clean controls: dE/dK-jump, N0-jump, and `boundary_K()` all
agree exactly. N=4 does not: `boundary_K()` returns 2.500, but the N0-jump
signature independently points to 6.400.

## Full transition structure

Every point where <N_0> changes by more than 0.3, with the dE/dK values on
either side (max possible N0 = N):

```
N=2 (max N0=2):
  K~3.950: N0 1->2, dE/dK 7.644->3.644 (slope jump 4.000)   <- only crossing

N=3 (max N0=3):
  K~0.050: N0 1->2, dE/dK 8.000->8.000 (slope jump 0.000)   <- SPURIOUS (see below)
  K~5.600: N0 2->3, dE/dK 5.660->1.660 (slope jump 4.000)   <- only real crossing

N=4 (max N0=4):
  K~2.500: N0 2->3, dE/dK 12.583->8.583 (slope jump 4.000)  <- NOT terminal
  K~6.400: N0 3->4, dE/dK 5.181->1.181 (slope jump 4.000)   <- terminal (N0=N)
```

The N=3 entry at K~0.05 is a numerical artifact, not a physical transition:
dE/dK is identical (8.000) immediately before and after it, i.e. E(K) has no
kink there. At K=0 exactly, nu_0 = nu_1 = 0 in the "nu0only" convention, so
the two lowest N0-sectors are degenerate and `eigh`'s arbitrary choice of
eigenvector among degenerate states flips the reported N0 from 1 to 2 across
that single grid point with no energetic consequence. `boundary_K()`'s
argmax-of-largest-slope-jump correctly ignores it (slope jump = 0.000, never
the maximum), so this artifact does not affect `boundary_K()`'s output for
N=3 -- it is noted here only because the N0-jump detector flags it.

## Diagnosis: why `boundary_K()` disagrees at N=4

`boundary_K()` is not buggy in its arithmetic -- it computes exactly what it
says: `Kv[1 + argmax(|diff(dE/dK)|)]`, the location of the single largest
slope discontinuity. The problem is that this assumption (one dominant
transition = the global argmax) silently breaks down once a system has more
than one genuine level crossing in the scanned window, which is exactly what
happens at N=4 and will keep happening for any N >= 4:

Every unit increase in <N_0> shifts the ground state to a sector where the
Hamiltonian's linear-in-K chemical-potential term has one more flavor-0 site
contributing, which changes dE/dK by a FIXED amount independent of which
occupation level the crossing happens at (each site contributes the same
-2*sqrt(x) slope). Confirmed directly: `|diff(dE/dK)|` at the N=4 K~2.5
crossing and at the K~6.4 crossing are BOTH exactly 4.000000 (bit-for-bit
identical, not just numerically close -- see the argsort dump in the
verification script's output). `np.argmax` breaks ties by returning the
FIRST maximum, i.e. the lowest-K tied crossing, so `boundary_K(N=4)` returns
the K~2.5 (N0: 2->3) crossing instead of the K~6.4 (N0: 3->4, the terminal
full-polarization transition analogous to what N=2 and N=3 return, since
those two systems only have one crossing each in range and so never
encounter the tie).

The trend that actually continues cleanly across N is the TERMINAL crossing
(N0 reaches its maximum value N, full flavor-0 polarization):
    N=2: 3.950,  N=3: 5.600,  N=4: 6.400  (monotonically increasing)
not `boundary_K(N=4)`'s 2.500, which is an earlier, non-terminal crossing
that N=2 and N=3 simply don't have an analogue of (they saturate in a single
step; N=4 needs two).

**Conclusion: `boundary_K()` returns the wrong crossing at N=4 because of an
exact tie in its argmax that the function does not handle -- it silently
picks the first of several equally-sized slope discontinuities rather than
the terminal one. The bug is in the tie-breaking assumption, not the energy
calculation.** The corrected N=4 boundary is **K ~ 6.4**, not 2.5.

## Consequence for Experiment 3

`run_exp3.py`'s `k_points()` called `boundary_K(N=4)` and used the return
value both directly (as "boundary") and halved (as "interior"), producing
K = 0, 1.25, 2.5. With the corrected boundary at K~6.4, the original
`results/noisy_N4_spot.csv` sits at K = 0, 1.25, 2.5 -- the "boundary" point
was actually probing the *first* (non-terminal) transition, and the
"interior" point (K=1.25) sits well before either transition, deep in the
untransitioned N0=2 plateau, not "interior" to anything.

`results/noisy_N4_spot.csv` is NOT rerun (per instructions); its K-point
labels should be read as "K=0 / first-transition K=2.5 / K=1.25" rather than
"K=0 / boundary / interior". `results/noiseless_N4_control.csv` (Bug 3) uses
the corrected points K = 0, 3.2, 6.4.

**Round 7 note (Table X caption).** Stated plainly for the paper's Table X,
which is fed by the three K points in `results/noisy_N4_spot.csv`: those
three values, K = 0.00, 1.25, 2.50, span the low-K region matched to the
noiseless restart-budget control (`exp07` / `results/noiseless_N4_control.csv`,
which evaluates the same K values), NOT the boundary region. The corrected
N=4 boundary is at K = 6.40; none of the three points reach it. The paper's
Section VI E text is already consistent with this (it says only "three
chemical potentials" and makes no boundary claim), and no boundary claim
should be added.
